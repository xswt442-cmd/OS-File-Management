OS-File-Management v1.0
========================

A simulated file system built in C++ for OS coursework.

Features:
- Virtual disk (1MB, 1024 blocks of 1024 bytes)
- FAT-based file allocation (explicit linked list)
- Bitmap free space management
- Multi-level directory tree
- Persistent storage to disk image

Commands: mkdir, rmdir, ls, cd, create, open, close,
          read, write, delete, cat, df, du, rename,
          stat, tree, format, help, exit

Enjoy testing!
